# Sasha's 34 keys (no HRM / no hold-taps)

Glove80 keymap for the [MoErgo Layout Editor](https://my.moergo.com/glove80/#/edit). Uses the 3×5 letter block plus two thumb keys per hand. No home-row mods and no hold-taps: every thumb key is a plain layer hold, and modifiers are ordinary keys on the Mods layer.

## Layout

Generated by `python3 render.py` from `keymap.json`, which also writes `layers.txt` with a binding-to-key table for diffing. Empty boxes are unbound keys.
